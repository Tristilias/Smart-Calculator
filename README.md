# Smart Calculator 🧮

## 🎯 Kegunaan
Membantu pengguna mengetahui berat badan ideal dan selisihnya dari berat saat ini, hanya dengan memasukkan tinggi dan berat badan.

## 🌐 English Summary
A simple Python console tool that calculates ideal body weight from height and weight input, with input validation and repeat mode.

---

## ✨ Features

### 🔢 Basic Calculations
Menghitung:
- Pertambahan
- Pengurangan
- Perkalian
- Pembagian

### 📐 Geometry Calculator
Menghitung:
- Luas bangun datar
- Keliling bangun datar
- Volume bangun ruang
- Luas permukaan bangun ruang

### 🌡 Temperature Converter
Konversi suhu:
- Celsius
- Fahrenheit
- Kelvin
- Reamur

### 💸 Discount Calculator
Menghitung:
- Potongan harga
- Harga akhir setelah diskon

### ⚖ BMI & Ideal Weight Calculator
Menghitung:
- BMI (Body Mass Index)
- Berat badan ideal
