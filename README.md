# Smart Calculator 🧮

## 🎯 Kegunaan
Kalkulator serba guna untuk perhitungan sehari-hari: hitung dasar, geometri, konversi suhu, diskon, dan BMI. Dibuat modular sehingga mudah dikembangkan.

## 🌐 English Summary
A modular multi-file C++ calculator with basic math, geometry, temperature conversion, discount, and BMI features.

---

## ✨ Features

### 🔢 Basic Calculations
Menghitung:
- Pertambahan
- Pengurangan
- Perkalian
- Pembagian

### 📐 Geometry Calculator
Menghitung:
- Luas bangun datar
- Keliling bangun datar
- Volume bangun ruang
- Luas permukaan bangun ruang

### 🌡 Temperature Converter
Konversi suhu:
- Celsius
- Fahrenheit
- Kelvin
- Reamur

### 💸 Discount Calculator
Menghitung:
- Potongan harga
- Harga akhir setelah diskon

### ⚖ BMI & Ideal Weight Calculator
Menghitung:
- BMI (Body Mass Index)
- Berat badan ideal
